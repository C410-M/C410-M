# FlashDelivery — Template básico de app web para delivery

Este repositório traz um front-end estático feito com HTML, CSS e JavaScript puro, ideal para apresentar um MVP de plataforma de delivery para restaurantes.

## Como usar
1. Faça o download ou clone o projeto.
2. Abra o arquivo `index.html` diretamente no navegador ou sirva os arquivos com qualquer servidor estático.
3. Personalize as seções conforme as necessidades do seu restaurante ou cliente.

## Estrutura
- `index.html`: estrutura das seções do site (hero, funcionalidades, cardápio, jornada e formulário de contato).
- `styles.css`: estilos globais, tokens de design (cores, espaçamentos, sombras) e responsividade.
- `script.js`: componentes dinâmicos como filtro de categorias, menu mobile e simulação de envio do formulário.

## Personalização rápida
- Atualize os dados do cardápio editando o array `menuData` em `script.js`.
- Ajuste cores e fontes modificando as variáveis CSS no topo de `styles.css`.
- Inclua novas seções ou elementos seguindo os padrões de classes existentes para manter a consistência visual.
